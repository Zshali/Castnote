# CastNote

> 字幕朗读 & 笔记

CastNote（字幕朗读 & 笔记）是一个 YouTube 学习辅助插件，支持字幕朗读和一键记笔记。观看英文视频时，可以配合沉浸式翻译使用中文字幕；字幕支持朗读并可调节语速。

听不懂的地方可以随时记录笔记，每条笔记会自动附带时间戳，点击即可跳转回原视频片段反复学习。笔记支持添加个人思考和疑问，并可一键导出为 TXT 或 Markdown 格式。

CastNote 完全免费开源，无需编程知识即可安装，也支持按照自己的习惯进行二次开发。

## 安装

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前这个 `immersive-caption-reader` 文件夹。
5. 刷新已经打开的 YouTube 页面。

## 使用

1. 打开普通 YouTube 视频并开启原始字幕。
2. 在沉浸式翻译中开启 YouTube 双语字幕，并把目标语言设置为简体中文。
3. 把鼠标移到视频上，在左上角点击“朗读”。
4. 可以暂停、继续、停止或调整倍速。

## 视频内快速记笔记

当中文字幕正在显示时，点击视频左上角的“记笔记 N”，或直接按键盘 `N`，插件会把当前中文字幕和视频时间保存到右侧 Notes。正在输入文字时，`N` 不会触发快捷键。

Notes 使用统一白板布局：屏幕抓取的中文字幕会用较大的高亮文字显示，每条高亮字幕下面都可以直接书写自己的心得，底部还可以继续写整篇总结。点击字幕时间戳会让视频跳回该位置并继续播放，所有手写内容都会自动保存；Notes 可以单独导出为 TXT 或 Markdown。

朗读时 YouTube 会临时静音，停止后恢复原来的音量和静音状态。插件只读取页面上当前显示的中文字幕，不会调用新的翻译或语音服务。

## 字幕记录（阶段 1A）

1. 等沉浸式翻译的中文字幕出现在视频上。
2. 点击“开始记录”。
3. 正常播放视频，插件会保存中文字幕、估算时间戳和视频信息。
4. 可以暂停记录、继续记录或停止记录。

记录保存在 Chrome 本地存储中，刷新页面后不会消失。

## 查看、写笔记和下载

1. 在视频左上角的插件控制区点击“打开原料包”（也可以点击浏览器工具栏中的“沉浸式字幕朗读器”图标）。
2. Chrome 会打开“视频知识原料包”侧边栏。
3. 在 Transcript 中查看已记录字幕，点击时间戳可以跳回视频。
4. 在 Notes 中按当前视频时间保存自己的笔记。
5. Transcript 右上角可以下载 TXT 或 Markdown 原料包。

## 隐私

CastNote 仅在浏览器本地读取和保存字幕、时间戳与笔记，不会把这些内容上传到服务器，也不需要 API Key。
